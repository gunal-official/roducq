## What these files are

- **306 unaltered viewport PNGs:** 51 fixtures × 375/768/1440 × light/dark. CSS pixels at DPR 1; no AI-generated screenshots.
- **204 supplemental full JPEGs:** every fixture at 375/1440 in both schemes. The app scrolls inside main, not the body. Authenticated full supplements flatten that internal scrolling and hide fixed app chrome **after** all measurement and the original PNG. Public/auth full supplements use normal full-page capture. These are below-fold review aids, **not** unaltered viewport or geometry proof.
- Every route also has seven-width geometry and real-container scroll-through results in the JSON. Screenshots are not being substituted for measurements.
- [Before](before/) contains eight unaltered baseline marketing screenshots from commit `8d1e2e9`; no reference-site screenshots were available.
- [Empty states](empty/) contains 39 additional, light-mode viewport captures (13 workspace/list surfaces × 375/768/1440). The separate empty-state audit also measures 320; it is not represented as a both-theme empty-state sweep.
- [Interaction captures](interactions/) show real modal menus, drawers, template fields/focus, reduced motion and exact zero-money rails. Public print PDFs are generated in memory; their byte sizes and white/plum checks are recorded in the interaction JSON, not persisted as PDF files. Template text is a safe fixture, never saved; onboarding creates no workspace.

## Results

Baseline **91/273** failing records → **0/714** populated light+dark records, **0/2,270** scroll-through samples. Empty sweep: **0/204** records and **0/630** scroll samples. All 24 interaction groups pass, plus the separate [onboarding persisted-theme proof](evidence/onboarding-themes.json). All seven required gates pass; **831 tests / 214 suites**, no failures/skips; PDF **14 documents / 20 pages**, zero findings.

Axe: **0 violations in 204 populated-page scans**, plus **102 empty-state scans** and **16 modal/menu scans**. This is not WCAG certification. [Incomplete contrast ledger](evidence/axe-incomplete-review.json) retains 104 node occurrences per main scheme and 104 in the empty run (gradients/overlap/short text); they are **not** counted as passes. Human assistive-technology, real device/keyboard/zoom, non-text/gradient/forced-color and live integration review remain release checks. Reference visual comparison was blocked.
